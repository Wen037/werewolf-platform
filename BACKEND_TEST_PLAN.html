🔧 Bugs Found & Fixed During Testing

  • Bug 1 — email.ts: new Resend() called at module load time before dotenv runs → crashes/hangs. Fixed with lazy init + test-mode bypass (if (NODE_ENV==='test') return).
  • Bug 2 — rateLimiter.ts: max: process.env.NODE_ENV === 'test' ? 1000 : 10 evaluated at module load (before dotenv). Fixed by making max a per-request function so dotenv has already run by first request.
  • Bug 3 — PlayerSpaceService.ts: Authenticated users with no prior venue interaction got myInteraction: undefined (omitted from JSON). Fixed by providing a default { isLiked:false, isSubscribed:false, myRating:undefined }.
  • Bug 4 — MatchService.leaveMatch(): MongoDB error "conflict at 'players'" — $pull and $push on the same players field in one findByIdAndUpdate call. Fixed by splitting into two sequential updates.
  • Bug 5 — MatchDTOs.ts: min_pax schema had .min(4) making max_pax=3 impossible. Lowered to .min(2) to allow small test games.
